# Learning & Memory — MCAT Foundations

## Classical Conditioning
UCS → UCR. CS paired with UCS → CR to CS. Discrimination vs generalization.

## Operant Conditioning
Reinforcement increases behavior; punishment decreases. Positive adds stimulus; negative removes aversive stimulus.

## Memory Systems
Sensory → short-term/working → long-term. Encoding, storage, retrieval failures explain different deficit patterns.

## Traps
- Mixing up negative reinforcement (removes bad) with punishment
- Confusing recall vs recognition in experiments

## High-Yield
Know examples for each conditioning type. Research methods passages often embed IV/DV in learning experiments.
